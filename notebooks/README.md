# Notebooks

This folder is reserved for optional Jupyter notebooks.

Suggested notebook sequence:

1. `01_eda.ipynb` — exploratory data analysis
2. `02_model_training.ipynb` — model experiments
3. `03_xai_analysis.ipynb` — SHAP/LIME experiments

The main reproducible workflow is kept in `src/` so it can be run from PowerShell.
